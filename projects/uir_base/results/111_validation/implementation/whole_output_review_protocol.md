# Whole-output assessment protocol

Representation experiments expose only deterministic JSON containing approved
claims, an explicit state and a trusted semantic digest. Assess the entire JSON
claim list against the authoritative synthetic catalog; no untrusted candidate
prose is passed through. Nonempty/all-request denominators and early refusal are
separate. This is bounded renderer/catalog support, not real-world fact truth.

Native model prose and historical mixed outputs are NOT_MEASURED. Seven-field
syntax-native renderer candidates may contain unsupported claims and are reported
as a separate ablation, never certified as safe because they are valid JSON.
Open judgment by two AI models is not independent whole-output human validation.
