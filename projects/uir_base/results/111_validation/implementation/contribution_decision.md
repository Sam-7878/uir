# Contribution decision

Position as an executable, bounded typed-contract systems study. The fair control
shares lexical parsing, information, policy and exact support verification; it
differs in absence of a public shared UIR artifact. Equal observations are retained,
not rewritten into UIR superiority. The measured structural benefit is a common
artifact/validator usable across the declared frontends/candidate formats.
Development effort, future integration savings and broad compositional proofs
remain hypotheses, not quantitative results.

Deterministic trusted catalogs win complete answers in both historical and new
output-layer development conditions. Seven-field syntax alignment does not make
values grounded; explicit ID enum binding is a separate stronger condition, usable
with or without UIR. The old negative FinQA/HaluEval/schema/AI-review results remain.

“Universal” denotes only the supported shared interface, not unrestricted language
or domain-independent objective truth. No hallucination-free, first-ever agent IR,
general faster/more accurate or statistically independent AI-error claim is allowed.
