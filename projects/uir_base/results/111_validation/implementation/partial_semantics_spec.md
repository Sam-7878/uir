# Partial and output scope

Raw candidates, structured accepted claims, deterministic rendered JSON and real
temporary-file action traces are distinct channels. A derived result can be
accepted only with its required operand closure. Dropping an unsupported
denominator cannot leave the ratio/growth assertion behind. Unit/period/entity
changes, cycles and division by zero have explicit negative tests.

FULL/PARTIAL/NONE concern the emitted approved answer, not whether a model
generated any text. Policy denial and clarification are different early states.
Partial permits a verified subset, not a free prose conclusion inferred from it.
Disabling partial rejects incomplete sets. Model-native prose AUCR remains
NOT_MEASURED. Bounded rendered-JSON assessment checks all emitted claim fields
relative to synthetic trusted catalogs, not objective real-world truth.
