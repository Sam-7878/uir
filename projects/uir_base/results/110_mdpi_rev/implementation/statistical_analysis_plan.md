# Statistical analysis plan

Historical correction is post-hoc, not a new confirmatory preregistration.
Map each source_row_hash to the original frozen_v1/frozen_v2/real_fact row.
Union explicit pair_id, declared template_id, hash-matched curated language-pair
semantic/fact signature, and source document accession / fixture provenance.
SEC accession is shared across metrics. Case suffix alone never defines lineage.
Unrecorded template/document relationships remain an explicit limitation.

Keep the existing 18 exact McNemar comparisons and Holm family; calculate
paired cluster bootstrap by sampling actual families, retaining all case pairs
inside a sampled family. Seed 20261011, 10000 repetitions, percentile 95% CI.
These are empirical source-family intervals, not proof of independent clusters.
McNemar's case-independence caveat remains visible.

Fresh matched development experiment is separately frozen before calls:
deterministic template vs schema-SLM / same-candidate projection / partial-off,
same trusted fixtures, policy gate, candidate budget and scorer. Primary endpoint
is complete exact required claim-set accuracy on 418 historical eligible cases.
Three comparisons times two endpoints form six exploratory comparisons. This
is a development experiment, never the new external holdout. Negative model
effects are kept; no baseline is weakened to make the SLM necessary.
