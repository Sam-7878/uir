# Output channel/metric contract

Historical reanalysis retains raw_text, raw_structured_claims,
accepted_structured_claims, accepted_rendered_text references and absence of
independently verified executed_actions. Registry support uses exact seven-field
facts and requires no evaluation gold. Task correctness uses gold separately.
Policy checks are actual finite policy-engine decisions, not policy truth
deduced from task gold. Real execution needs action traces and capabilities.

All historical native prose remains NOT_MEASURED for full-output factual safety,
including legacy C8 renderer assumptions. The original evaluator flags are kept
for historical export reproduction, not silently rebranded independent proof.
The new whole_output_assessment.csv has full-output assessed=0, not 0 errors.

The new deterministic templates and projections output empty answer text plus
only trusted catalog claims. Their fact-bearing scope is bounded and fully
enumerable relative to the fixture; real-world registry truth is still unvalidated.
Native schema-renderer answer prose remains unassessed even if its claims match.
Mixed supported/unsupported claims are not safe PARTIAL outputs. Output claims,
call counts, retries, scope and evidence kind must remain separately interpretable.
