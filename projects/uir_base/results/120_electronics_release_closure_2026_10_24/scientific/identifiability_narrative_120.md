# Causal Identifiability and Response Reuse Specification (Stage 120)

**Manuscript Title:** Policy-and-Evidence Intermediate Contracts for Generative-AI Software: Independent Interpreter Conformance and Query-Aware Grounding  
**Stage:** 120  
**Purpose:** Formal specification of sample structure, causal identifiability boundaries, and response reuse topology in the secondary factorial experiment.

## 1. Experimental Sample Structure: Matched Outcomes vs. Independent Invocations

In the secondary factorial evaluation ($2 \times 2 \times 2$ design):
- **Primary Cases ($N_{\text{case}} = 240$):**
  - $120$ Authorized cases (`ALLOW` query contracts)
  - $120$ Unauthorized cases (`DENY` query contracts)
- **Experimental Conditions ($K = 8$):**
  - Factor 1 (Representation): UIR Canonical JSON vs. Compact Specialized
  - Factor 2 (Fact Selector): Deterministic Rule Selector vs. Generative SLM Selector (Phi-3.5-mini)
  - Factor 3 (Renderer): Deterministic Template Format vs. Generative SLM Renderer (Phi-3.5-mini)
- **Total Outcome Rows:**
  $$N_{\text{factorial}} = 240 \text{ cases} \times 8 \text{ conditions} = 1,920 \text{ matched outcome rows}$$

### Critical Epistemic Distinction (Negative Assertion B120-09):
The $1,920$ outcome rows **must NOT be characterized as $1,920$ statistically independent model inference calls**.
Instead, the inference topology consists of:
- **Unique Model Invocations ($N_{\text{invoke}} = 480$):**
  - Generative Selector: $240$ invocations ($120$ under ALLOW, $120$ under DENY).
  - Generative Renderer: $240$ invocations ($120$ under ALLOW, $120$ under DENY).
- **Deterministic Response Reuse:**
  Because the query semantics between UIR Canonical JSON and Compact Specialized contracts are mathematically isomorphic, candidate proposals generated by the SLM under identical prompt semantics were evaluated across representation branches using a matched-pairs response reuse design. This cleanly isolates the syntactic representation effect while controlling for stochastic sampling variance.

## 2. Granular Metric Denominators: ALLOW vs. DENY Conditioning

When reporting empirical rates, the conditioning state must always be explicitly stated:

1. **SLM Fact Selector Exact Match:**
   - **Conditioned on Authorized Requests (`ALLOW`, $n=120$):** Exactly $\mathbf{0 / 120}$ ($0.0\%$). The model captured target fact identifiers with $100\%$ recall, but invariably over-selected adjacent distractor facts from the evidence registry context.
   - **Conditioned on Unauthorized Requests (`DENY`, $n=120$):** The pre-inference policy authority intercepted all $120$ unauthorized contracts, yielding deterministic suppression.
   - **Pooled Over All Authorized Cases:** $0/120$ ($0.0\%$).

2. **Deterministic Evidence Guard Recovery Rate:**
   - Under deterministic template rendering (`Path A`), the evidence guard applied set intersection:
     $$\mathcal{F}_{\text{acc}} = \mathcal{F}_{\text{prop}} \cap \mathcal{F}_{\text{auth}} \cap \mathcal{F}_{\text{req}}(\mathcal{C}_{\text{query}})$$
     purging all distractor facts and recovering $\mathbf{120 / 120}$ ($100.0\%$) exact ground-truth displays.

3. **Generative Renderer Omission Rate:**
   - Under generative rendering (`Path B`), the model failed to output all required fact lines in $44$ out of $120$ authorized trials, producing a **$36.67\%$ omission penalty** ($76/120$, $63.33\%$ complete displays).
   - Under unauthorized trials ($n=120$), zero leaks occurred because the upstream policy authority had blocked display admission ($120/120$ blocked). Thus, generative rendering provided **zero incremental safety benefit** while causing significant utility loss.

## 3. Representation Neutrality Boundary

Across all $1,920$ factorial cells, the contrast between UIR Canonical JSON and Compact Specialized contracts yielded:
$$\Delta_{\text{repr}} = \text{Metric}(\text{UIR}) - \text{Metric}(\text{Specialized}) = \mathbf{0.0\%}$$
for every evaluated dependent variable (ALLOW exact match, Macro F1, Complete Display, and DENY Blockage).

### Identifiability Conclusion:
- This equivalence proves that **dependability is an architectural invariant of the deterministic contract boundary** (pre-inference authority and post-inference guard) rather than an intrinsic virtue of JSON serialization syntax.
- **Forbidden Claim:** The manuscript does NOT claim that UIR possesses intrinsic safety superiority over compact representations.
