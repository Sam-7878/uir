# UIR base research

Base project for typed UIR execution contracts and grounded-output research.
Shared implementation lives in root `src/` and `crates/`, not in a second copy here.

Project-wide design belongs in `docs/`, reusable milestone inputs in `resources/`,
and evaluation/orchestration sources in `evaluation/`, `scripts/` and the existing
research modules. Manuscript workspaces are local/private under `paper/`.
All task-specific data, reports, pictures, work orders and logs belong to
`results/<task_id>/`. Private work orders/reviews/work reports stay at
`docs/work_reports/uir_base/<task_id>/` relative to repository root, LOCAL ONLY.

See [repository layout](../../docs/architecture/PROJECT_LAYOUT.md).
